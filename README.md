# MaiBot 消息防抖与合并插件 (Message-Debouncing)

短时间内合并同会话、同用户的连续短句消息，再统一提交给 MaiBot 思考回复。有效解决 QQ 聊天中用户高频“断句发消息”导致的机器人疯狂插话、重复触发与 Token 严重浪费问题。

## 工作原理

1. 消息拦截：通过入站 Hook 捕获用户发送的即时消息。
2. 窗口计时：若同一用户在设定防抖窗口内（如 2.5 秒）连续发送多条消息，将消息暂存入内存队列。
3. 超时结算：当该用户停止输入达到窗口时长后，将暂存的短句按时序合并为一条完整的长消息。
4. 管道递交：将合并后的消息投递给 MaiBot 聊天循环，大模型仅需执行一次思考即可完整回答。

## 配置项说明

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `[plugin].enabled` | bool | `true` | 是否启用消息防抖合并 |
| `[debounce].window_seconds` | float | `2.5` | 防抖等待时间窗口（秒） |
| `[debounce].max_merged_messages` | int | `8` | 单次合并的最大消息条数上限 |
| `[debounce].separator` | string | `"\n"` | 多条消息合并时的文本拼接分隔符 |
